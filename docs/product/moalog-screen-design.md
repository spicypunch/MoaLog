앱 이름: 모아로그(부부가계부) · 프로젝트명: MoaLog

작성일: 2026-09-08

기준 문서: [기능 이관 명세서](./moalog-spec.md)

## 1. 디자인 범위

**기본 화면 20종과 공통 바텀시트 9종**으로 구성한다. 화면의 탭, 신규/수정 모드, 빈 상태는 같은 화면의 변형으로 그린다. 바텀시트는 화면 아래에서 올라오는 짧은 입력·선택 패널이다.

이번 디자인은 **모바일 세로 화면**을 기준으로 제안한다. Android/iOS 공통으로 구현할 수 있는 구성이다. 플랫폼과 시각 스타일은 아직 확정 요구사항이 아니며, 여기서는 화면 간 일관성을 위한 디자인 초안을 제공한다.

주요 탐색은 `홈 / 계획 / 기록 / 자산 / 더보기` 5개 탭이다. 하단 탭은 각 메뉴의 첫 화면에만 두고, 상세·입력 화면에는 뒤로 가기와 저장 동작을 배치한다.

## 2. Stitch에 먼저 전달할 공통 요청문

아래 내용을 먼저 전달한 다음, 4절의 화면별 요청문을 필요한 화면마다 사용한다. 한 화면의 스타일이 정해지면 다음 화면에서도 같은 색상·컴포넌트·간격을 유지하도록 요청한다.

```text
두 사람의 수입, 지출, 저축, 목적통장과 관리비를 관리하는 한국어 모바일 가계부 앱을 디자인해줘.
앱 이름은 ‘모아로그(부부가계부)’이고, 화면의 브랜드 표기는 ‘모아로그’로 사용해줘. 모바일 세로 390px 너비를 기준으로 만들고 콘텐츠가 길면 세로로 스크롤되게 해줘.

시각 방향은 차분하고 따뜻한 생활 금융 앱이야. 밝은 아이보리 배경, 흰색 카드, 진한 청록색 주요 버튼, 차콜 본문을 사용해줘. 과소비에는 붉은색과 ‘과소비’ 텍스트를 함께 사용해줘. 예상은 파란색 배지, 확정은 중립 배지로 구분해줘.
큰 금액과 명확한 항목명을 중심으로 구성해줘. 과한 일러스트보다 읽기 쉬운 숫자, 적절한 여백, 단순한 차트를 우선해줘. 본문 16px, 보조 정보 14px, 핵심 금액 28~32px, 좌우 여백 20px, 카드 모서리 16px를 출발점으로 사용해줘. 터치 영역은 최소 48px로 확보해줘.

하단 탭은 ‘홈 / 계획 / 기록 / 자산 / 더보기’야. 각 탭의 첫 화면에는 하단 탭을, 상세·입력 화면에는 뒤로 가기와 페이지 제목을 넣어줘. 입력 화면은 키보드가 올라와도 하단 저장 버튼이 가려지지 않게 해줘.
금액은 ‘6,500,000원’처럼 천 단위 쉼표와 원 단위를 쓰고 오른쪽 정렬해줘. 긴 항목명은 줄바꿈하고 금액은 잘리지 않게 해줘.

사용자가 수정하는 금액과 자동 합계를 구분해줘. 빈값은 ‘미입력’, 입력된 0은 ‘0원’으로 보여줘. 예상과 확정은 색상 외에 텍스트로도 구분해줘.
지출의 ‘귀속 월’과 ‘실제 지출일’은 별도 필드야. 저축 기록과 보유 자산 잔액도 다른 정보야. 저축률이나 목표 달성률이 100%를 넘는 경우 숫자를 그대로 보여줄 수 있어야 해.

별도 요청이 없는 로그인, 파트너 초대, 은행 연결, 송금, AI 추천, 채팅, 유료 구독 화면은 만들지 말아줘.
각 디자인 프레임의 이름은 내가 제공하는 P01, P02 등의 화면 ID와 화면명으로 붙여줘. ID 자체는 앱 사용자 화면에 노출하지 말아줘.
```

색상과 크기는 제안값이다. 브랜드를 변경하더라도 아래 화면의 정보와 동작은 유지한다.

## 3. 디자인 예시 데이터

아래는 화면 연결을 확인하기 위해 정리한 **가상 디자인 데이터**다. 기존 시트의 원본 결산값이나 실제 사용자 확정 데이터가 아니다. Stitch에는 다음 데이터 블록도 함께 전달할 수 있다.

| 영역 | 예시 |
|---|---|
| 가계부 | 모아로그 / 수아·종민 |
| 기준 | 2026년, 선택 월 5월 |
| 연간 예상 포함 합계 | 수입 78,000,000원 / 지출 36,000,000원 / 목적통장 포함 저축 39,000,000원 |
| 연간 저축 | 목표 50,000,000원 / 달성률 78% / 저축률 50% |
| 5월 요약 | 수입 6,500,000원 / 고정비 2,400,000원 / 변동비 600,000원 / 총지출 3,000,000원 |
| 5월 저축 | 목적통장 포함 3,250,000원 / 순저축 2,500,000원 / 각각 저축률 50%, 38.5% |
| 5월 변동비 | 생활비 초과 360,000원 / 데이트비 140,000원 / 경조사비 100,000원 |
| 5월 과소비 | 생활비 초과 중 120,000원에만 과소비 체크 |
| 월급 | 종민 3,300,000원 / 수아 3,200,000원 |
| 투자 배분 예시 | 총월급의 40% = 2,600,000원 / 하위 합계 2,500,000원 / 차액 100,000원 |
| 자산 | 4월 67,585,721원 → 5월 69,312,221원 / 증감 +1,726,500원 |
| 목적통장 | 데이트 300,000원 / 여행 700,000원 / 경조사 600,000원 / 효도 400,000원 / 합계 2,000,000원 |

홈의 연간 합계와 월 계획의 일부 항목은 예상값을 포함한다. ‘39,000,000원을 이미 저축했어요’처럼 실제 완료를 단정하는 문구 대신 ‘연간 저축 · 예상 포함’을 사용한다. 월급 배분액은 독립된 계획표이므로 실제 지출 합계와 동일할 필요가 없다.

## 4. 화면별 설계와 요청문

### P01. 가계부 시작 설정

**목적:** 첫 실행 시 가계부의 이름과 기준을 정한다.

**위에서 아래로:** 앱 이름과 짧은 설명 → 가계부 이름 → 두 사람 이름 → 기준 연도 → 연 저축 목표 → 시작 버튼.

**입력:** 가계부 이름, 사람 1 이름, 사람 2 이름, 기준 연도. 목표액은 선택 입력이다. 두 사람 이름은 계정 가입과 별개다.

**버튼·이동:** `가계부 시작하기` → P02. 목표를 입력하지 않은 경우 홈에 목표 설정 안내를 표시한다.

**추가 상태:** 이름 누락 시 필드 바로 아래 오류, 목표 미입력 상태.

```text
P01 ‘가계부 시작 설정’을 디자인해줘. 제목은 ‘우리의 돈 관리를 시작해요’, 설명은 ‘수입부터 저축까지, 함께 정리해요’야.
‘가계부 이름’, ‘첫 번째 사람 이름’, ‘두 번째 사람 이름’, ‘기준 연도’, ‘연 저축 목표’ 입력란을 세로로 배치해줘. 예시는 모아로그, 수아, 종민, 2026년, 50,000,000원이야. 목표에는 ‘나중에 설정할 수 있어요’라는 안내를 넣어줘.
하단에 ‘가계부 시작하기’ 버튼을 배치해줘. 하단 탭은 없어. 기본 입력 상태와 필수 이름 누락 오류 상태를 그려줘.
```

### P02. 홈

**목적:** 연간 돈의 흐름과 저축 목표를 빠르게 확인한다.

**위에서 아래로:** 가계부 이름·구성원 → 연도 선택 → 연 목표 카드 → 연간 수입·지출·저축 요약 → 구성 분석 바로가기 → 선택 월 과소비 → 초기 작성 안내.

**핵심 정보:** 목표 5천만원, 연간 예상 포함 저축 3,900만원, 달성률 78%, 저축률 50%. 총저축 옆에 목적통장 포함이라는 기준을 표시한다.

**버튼·이동:** 목표 수정 → B02 / 수입·지출·저축 카드 → P05 해당 구역 / 구성 분석 → P03 / 과소비 카드 → P11 해당 월 필터 / `지출 기록` → P12.

**추가 상태:** 데이터 없음, 목표 없음, 달성률 100% 초과, 비율 계산 불가. 첫 사용 안내는 데이터 작성 후 접을 수 있다.

```text
P02 ‘홈’을 디자인해줘. 하단 탭은 홈이 선택되어 있어. 상단에 ‘모아로그’, ‘수아 · 종민’, ‘2026년’ 선택기를 넣어줘.
가장 큰 카드에는 ‘연 저축 목표 50,000,000원’, ‘연간 저축 · 예상 포함 39,000,000원’, 달성률 78%와 진행 막대, 목표 수정 버튼을 넣어줘. 저축 기준은 ‘목적통장 포함’으로 표시해줘.
아래에 연간 수입 78,000,000원, 지출 36,000,000원, 저축률 50%를 정리하고 ‘연간 상세 보기’를 넣어줘. 구성 분석 바로가기와 ‘5월 과소비 120,000원’ 카드를 배치해줘. 지출 기록 버튼도 제공해줘.
기본 화면, 아직 기록이 없는 화면, 목표 달성률이 120%인 화면을 각각 같은 레이아웃의 변형으로 그려줘. 예상 포함 금액을 이미 달성한 실적처럼 표현하지 말아줘.
```

### P03. 지출·저축 구성 분석

**목적:** 어떤 항목이 전체에서 얼마나 차지하는지 확인한다.

**위에서 아래로:** 뒤로 가기·제목 → `고정지출 / 변동지출 / 저축·투자` 탭 → 기간 → 합계 → 구성 차트 → 금액·비중 목록.

**기간:** 고정지출과 저축·투자는 연간. 변동지출은 월별 또는 연간 선택.

**버튼·이동:** 변동지출 카테고리 → P11의 해당 필터 / 다른 분류 → P05 해당 구역. 기간 선택 → B01.

**추가 상태:** 데이터 없음, 음수 항목 포함 시 막대와 금액 목록으로 전환. 비중의 분모는 선택 기간과 일치하는 설계안이다.

```text
P03 ‘구성 분석’을 디자인해줘. 상단에 뒤로 가기, 제목, ‘고정지출 / 변동지출 / 저축·투자’ 탭이 있어.
변동지출 탭의 2026년 5월 화면을 먼저 그려줘. 합계 600,000원, 생활비 초과 360,000원 60%, 데이트비 140,000원 23.3%, 경조사비 100,000원 16.7%를 도넛 차트와 아래 목록에 보여줘. 목록 행은 이름, 금액, 비중 순서야.
기간은 월 또는 연간으로 바꿀 수 있어. 고정지출과 저축·투자 탭에서는 기간이 연간으로 표시되는 변형도 만들어줘. 음수 항목이 있을 때는 도넛 대신 부호가 보이는 막대와 금액 목록을 사용해줘.
```

### P04. 월별 계획

**목적:** 한 달의 수입·고정비·변동비·저축을 확인하고 입력한다.

**위에서 아래로:** 제목·연간 보기 → 연월 이동 → 월급 배분·고정비 점검 바로가기 → 월 요약 → `수입 / 고정지출 / 변동지출 / 저축·투자` 탭 → 분류별 항목 목록.

**목록:** 항목명, 공동/개인, 금액, 예상/확정/미입력. 변동지출은 읽기 전용 카테고리 합계다.

**저축 탭:** 목적통장 포함 합계와 순저축을 나란히 표시하고 각 저축률을 붙인다.

**버튼·이동:** 항목 추가·행 선택 → P06 / 연간 보기 → P05 / 여러 달 적용 → P07 / 바로가기 → P08·P10 / 변동지출 행 → P11.

**추가 상태:** 네 탭을 별도 변형 프레임으로 그린다. 항목 없는 월, 일부 미입력, 예상과 확정 혼재를 포함한다.

```text
P04 ‘월별 계획’을 디자인해줘. 하단 탭은 계획이 선택되어 있어. 상단은 ‘월별 계획’과 ‘연간 보기’, 그 아래 이전·다음 달 화살표가 있는 ‘2026년 5월’ 선택기야.
‘월급 배분’과 ‘고정비 점검’ 바로가기를 넣고 수입 6,500,000원, 총지출 3,000,000원, 목적통장 포함 저축 3,250,000원의 월 요약을 보여줘.
본문은 수입, 고정지출, 변동지출, 저축·투자 네 탭으로 구성하고 탭별 프레임을 만들어줘. 항목 행에는 이름, 공동 또는 사람 이름, 오른쪽 금액, 예상·확정 배지가 있어. 수입 예시는 종민 월급 3,300,000원, 수아 월급 3,200,000원이야.
저축 탭에는 포함저축 3,250,000원·50%와 순저축 2,500,000원·38.5%를 보여줘. 입력 가능한 탭에는 ‘항목 추가’와 ‘여러 달에 적용’을 제공하고, 변동지출에는 ‘지출 기록 보기’를 넣어줘.
```

### P05. 연간 한눈에 보기

**목적:** 원본의 가로 12개월 표를 앱에서 비교한다.

**위에서 아래로:** 제목·연도 → 요약 → 수입·고정지출·변동지출·저축 구역 선택 → 항목×12개월 표 → 연 합계.

**표 설계:** 왼쪽 항목명과 위쪽 월 헤더 고정. 가로 스크롤 가능 표시. 선택 항목의 연 합계는 월별 표와 별도 요약에 표시해 작은 화면에서 접근 가능하게 한다.

**버튼·이동:** 입력 가능한 셀 → P06의 해당 월·항목 / 변동지출 셀 → P11 / 월 헤더 → P04.

**추가 상태:** 빈칸·0원·예상·확정, 음수 저축. 표는 유일한 입력 경로가 아니며 P04에서도 같은 데이터를 편집할 수 있다.

```text
P05 ‘연간 한눈에 보기’를 디자인해줘. 2026년의 수입·고정지출·변동지출·저축을 구역 선택기로 바꿔 볼 수 있는 모바일 표 화면이야.
항목명이 왼쪽에 고정되고 1월부터 12월까지 가로 스크롤되는 표를 만들어줘. 상단 월 헤더도 고정하고 가로로 더 볼 수 있다는 시각적 단서를 넣어줘. 390px 화면에 12개월을 억지로 축소하지 말아줘.
수입 예시로 종민 월급, 수아 월급, 부수입을 표시하고 선택 항목의 연간 합계를 표 위에 보여줘. 셀에 예상·확정 상태, 미입력, 0원이 구분되어야 해. 뒤로 가기를 넣고 하단 탭은 없어.
```

### P06. 계획 항목 입력·수정

**목적:** 수입·고정비·저축의 특정 월 항목을 작성한다.

**공통 입력:** 귀속 월, 항목명, 금액, 예상/확정 상태, 메모. 소속 사람/공동과 분류는 종류에 맞게 표시한다.

**종류별 변형:** 수입은 소득 항목과 사람 / 고정비는 지출 분류 / 저축은 자산 분류·목적통장 여부·순저축 포함 여부·음수 입력을 제공한다.

**버튼·이동:** 저장 → 원래 월별 계획 / `저장 후 여러 달에 적용` → P07. 기존 월 금액은 더보기에서 지우며, 항목 전체 보관은 P19에서 구분한다.

**추가 상태:** 금액 오류, 저장 중, 저장 실패 시 입력값 보존, 변경 후 뒤로 가기 확인. 순저축 포함 정책은 기존 명세의 결정 전 설계안이다.

```text
P06 ‘계획 항목 입력’을 수입·고정지출·저축 세 가지 폼 변형으로 디자인해줘. 상단에는 뒤로 가기와 제목, 하단에는 저장 버튼이 있어.
공통 필드는 귀속 월, 항목명, 금액, 예상/확정 선택, 메모야. 고정지출은 카테고리와 공동/수아/종민 선택이 있어. 수입은 소득이 귀속되는 사람을 선택해.
저축 폼은 예적금·청약·주식·부동산·대출원금·퇴직금 분류, 목적통장 여부, 순저축 포함 여부를 보여줘. 금액은 -350,000원처럼 음수 입력도 가능하고 ‘인출은 음수로 입력해요’라는 설명을 붙여줘.
저장 버튼 아래에 ‘저장 후 여러 달에 적용’ 보조 동작을 넣고 키보드가 열린 화면과 필수 금액 오류 상태도 그려줘.
```

### P07. 여러 달에 적용

**목적:** 반복 입력을 줄이면서 이미 작성한 금액을 확인하고 복사한다.

**1단계:** 기준 월·가져올 항목 → 대상 월 다중 선택 → 기존 값 유지/덮어쓰기 선택.

**2단계:** 항목·대상 월·기존 금액·변경 금액 비교. 기존값이 없는 곳은 ‘미입력’으로 표시. 최종 적용 개수와 버튼.

**버튼·이동:** `변경 내용 확인` → 같은 화면 2단계 / `적용하기` → P04. 고정비 점검에서 들어오면 출처를 ‘고정비 점검’으로 표시한다.

**추가 상태:** 선택 없음, 덮어쓸 항목 있음, 적용 완료. 저장은 최종 버튼에서 수행한다.

```text
P07 ‘여러 달에 적용’을 두 단계의 화면으로 디자인해줘.
첫 화면에는 기준 ‘2026년 5월’, 선택 항목 ‘종민 월급 3,300,000원’, 1~12월 다중 선택 칩을 넣어줘. 6~12월을 선택한 모습과 ‘기존 값 유지 / 선택한 값으로 바꾸기’ 옵션을 보여줘. 버튼은 ‘변경 내용 확인’이야.
두 번째 화면은 대상 월별 기존 금액과 적용 후 금액을 비교하는 목록이야. 바뀌는 값이 눈에 띄고, 하단에는 ‘7개 월에 적용하기’ 버튼이 있어. 이전 단계로 돌아갈 수 있어야 해. 같은 구조를 고정비 점검에서 항목을 가져올 때도 사용할 수 있게 해줘.
```

### P08. 월급 배분

**목적:** 두 사람 급여와 사용처별 배분 계획을 정리한다.

**위에서 아래로:** 제목 → 두 사람 급여·합계 → 생활비·용돈·목적통장·고정변동비·투자 카드 → 배분 항목 추가.

**대분류 카드:** 이름, 계산 방식, 배분액, 하위 합계, 차액. 비율과 금액을 이름에 합쳐 숨기지 않는다.

**버튼·이동:** 월급 수정 → B04 / 대분류 → P09 / 추가 → B06 신규 모드.

**추가 상태:** 월급 없음, 배분액과 하위 합계 일치/불일치. 계획표와 연간 가계부는 자동으로 같은 금액이 되지 않는다.

```text
P08 ‘월급 배분’을 디자인해줘. 두 사람 월급은 종민 3,300,000원, 수아 3,200,000원이고 합계는 6,500,000원이야. 급여 카드에 수정 버튼을 넣어줘.
아래에 생활비, 용돈, 목적통장, 고정변동비, 투자 대분류를 세로 카드로 보여줘. 카드에는 계산 기준, 배분액, 세부 합계, 차액이 있어.
투자 카드는 ‘총월급의 40%’, ‘배분액 2,600,000원’, ‘세부 합계 2,500,000원’, ‘차액 100,000원’을 표시해줘. 금액이 다르다고 자동 조정하지 않고 차이를 확인할 수 있는 모습으로 그려줘. 카드 선택으로 상세에 들어가며 하단에는 ‘배분 항목 추가’가 있어.
```

### P09. 배분 항목 상세

**목적:** 대분류 안의 중·소분류, 금액, 거래수단을 편집한다.

**위에서 아래로:** 대분류명·편집 → 배분액/세부합계/차액 → 중분류 목록 → 펼친 소분류 → 항목 추가.

**행 구성:** 항목명, 금액, 거래수단, 하위 항목 펼치기. 중·소분류 깊이는 들여쓰기와 제목 스타일로 구분한다.

**버튼·이동:** 대분류 계산 편집·하위 행 편집·추가 → B06. 대분류 합계는 선택한 계산 방식에 따라 읽기 전용이다.

**추가 상태:** 하위 없음, 차액 있음, 긴 통장명, 합산·차감·비율 방식.

```text
P09 ‘배분 항목 상세’를 투자 분류 예시로 디자인해줘. 상단에 배분액 2,600,000원, 세부 합계 2,500,000원, 차액 100,000원을 표시하고 계산 방식 편집 버튼을 넣어줘.
중분류는 적금 800,000원, ISA 800,000원, 개인연금저축 400,000원, IRP 200,000원, 금/주식 300,000원이야. ISA를 펼치면 수아 400,000원과 종민 400,000원이 나와.
각 항목은 금액과 거래수단을 보여주고 행을 누르면 편집해. 하위 항목의 들여쓰기와 펼치기 아이콘을 명확하게 만들고 ‘하위 항목 추가’를 제공해줘. 3단계 구조에서도 금액이 오른쪽에 잘 보이도록 해줘.
```

### P10. 고정비 점검

**목적:** 가계부에 반영하기 전 두 사람의 고정비를 점검한다.

**위에서 아래로:** 제목 → 월 총고정비 → 공동/수아/종민 구분 → 항목 목록과 그룹 합계 → 항목 추가 → 계획에 가져오기.

**버튼·이동:** 행 추가·수정 → B05 / `선택 항목을 계획에 가져오기` → 선택 모드 → P07.

**추가 상태:** 그룹별 빈 목록, 선택 모드, 같은 항목이 이미 계획에 있음. 연 환산액은 원본 계산 정책 확정 전 주요 수치로 넣지 않는다.

```text
P10 ‘고정비 점검’을 디자인해줘. 제목 아래 ‘매월 고정비 합계’를 크게 보여주고 공동, 수아, 종민 세 구분을 제공해줘.
공동 목록 예시는 식비 400,000원, 생활비 200,000원, 대출이자 900,000원, 관리비 300,000원, 구독료 100,000원이야. 공동 합계 1,900,000원을 표시해줘.
각 행에는 이름, 월 금액, 편집 동작을 넣어줘. ‘항목 추가’와 ‘선택 항목을 계획에 가져오기’ 버튼을 배치해줘. 일반 목록과 항목 체크박스가 나온 선택 모드를 그려줘.
```

### P11. 지출 기록

**목적:** 변동지출을 조회하고 필요한 기록을 찾는다.

**위에서 아래로:** 제목·월 선택 → 변동지출 합계·과소비 합계 → 필터와 정렬 → 날짜별 지출 목록 → 지출 추가.

**행 구성:** 카테고리, 상세 내용, 금액, 실제 일자, 과소비 배지. 귀속 월과 실제 일자 월이 다르면 둘 다 표시한다.

**합계 정책:** 필터가 걸리면 ‘필터 결과 합계’로 제목을 바꾼다. 상단 선택 월 전체 합계와 혼동시키지 않는다.

**버튼·이동:** 추가·행 선택 → P12 / 필터 → B03 / 월 → B01.

**추가 상태:** 월 기록 없음, 필터 결과 없음, 과소비만 보기, 일자 없는 기록.

```text
P11 ‘지출 기록’을 디자인해줘. 하단 탭에서 기록을 선택해줘. 2026년 5월의 변동지출 합계 600,000원과 과소비 120,000원을 상단에 보여줘.
카테고리, 과소비 여부 필터와 최신순/오래된순 정렬을 넣고 날짜별 목록을 만들어줘. 기록 예시는 생활비 초과 240,000원, 생활비 초과 120,000원, 데이트 140,000원, 경조사 100,000원이야. 120,000원 기록에만 과소비 배지를 붙여줘.
하단 탭 위에 ‘지출 추가’ 버튼을 넣어줘. 월 기록 없음, 필터 결과 없음, 과소비 필터 적용 화면도 만들어줘. 날짜와 귀속 월이 다를 때 둘 다 표시되는 행도 별도 변형으로 보여줘.
```

### P12. 지출 입력·수정

**목적:** 가장 자주 쓰는 지출 입력을 빠르게 완료한다.

**위에서 아래로:** 제목 → 큰 금액 입력 → 카테고리 → 귀속 월 → 실제 지출일 → 상세 내용 → 과소비 체크 → 저장.

**필수:** 금액, 카테고리, 귀속 월. 실제 일자와 상세는 선택.

**버튼·이동:** 저장 → P11 원래 필터 / 수정 모드 더보기 → 삭제 확인 D01.

**추가 상태:** 키보드, 필수 누락, 과소비 체크 시 ‘120,000원 전체를 과소비로 표시’, 귀속 월과 일자 불일치. 날짜가 다르다는 이유만으로 저장을 막지 않는다.

```text
P12 ‘지출 입력’을 디자인해줘. 큰 금액 입력을 맨 위에 두고 아래에 카테고리, 귀속 월, 실제 지출일, 상세 내용, 과소비 토글을 배치해줘.
카테고리는 생활비 초과, 데이트비, 여행비, 경조사비, 효도비, 기타 예산 중 선택해. 필수는 금액·카테고리·귀속 월이고 실제 지출일과 상세는 선택이야. 귀속 월에는 ‘이 지출을 합산할 달이에요’라는 설명을 붙여줘.
금액 120,000원에 과소비를 켠 상태에서는 ‘120,000원 전체를 과소비로 표시해요’라고 보여줘. 저장 버튼은 키보드 위에서도 보이게 해줘. 신규, 수정, 필수값 누락 상태를 그려줘. 귀속 월 1월과 실제 일자 2월 1일을 함께 표시할 수 있어야 해.
```

### P13. 자산 현황

**목적:** 월별로 입력한 보유 자산과 증감을 확인한다.

**위에서 아래로:** 월 선택 → 해당 월 자산 총액·전월 증감·상태 → 추이 차트 → 자산별 금액 → 목적통장 바로가기 → 저축 기록 바로가기.

**중요 구분:** 이 화면의 총액은 자산 표에 입력된 항목의 합계다. 별도 목적통장 잔액을 무조건 합쳐 표시하지 않는다. 저축 납입액도 이 총액으로 대체하지 않는다.

**버튼·이동:** 자산 항목 → P14 / 신규 자산 → B07 / 목적통장 → P15 / 저축 기록 → P04 저축 탭.

**추가 상태:** 자산 없음, 예상 월, 전월 미입력. 과거 확정과 미래 예상 구간을 실선·점선 및 범례로 구분한다.

```text
P13 ‘자산 현황’을 디자인해줘. 하단 탭은 자산이 선택되어 있어. 2026년 5월 자산 총액 69,312,221원과 전월 대비 +1,726,500원을 보여줘.
월별 추이 차트는 확정 구간 실선, 예상 구간 점선으로 구분하고 범례를 붙여줘. 자산 목록 예시는 수아 ISA 2,400,000원, 종민 ISA 1,600,000원, 수아 비상금 14,430,701원, 종민 비상금 48,181,520원, 적금 2,700,000원이야. 합계와 항목 금액이 일치하게 해줘.
‘자산 항목 추가’, ‘목적통장 현황’, ‘이번 달 저축 기록’ 진입점을 넣어줘. 보유 자산과 월 저축 납입액을 다른 정보로 구분해줘.
```

### P14. 자산 항목 상세

**목적:** 하나의 자산·통장의 월 금액과 계산 방식을 관리한다.

**위에서 아래로:** 항목명·개인/공동 → 선택 월 금액·상태 → 추이 → 월별 금액 목록 → 예상 금액 설정.

**입력:** 직접 월 금액 입력 또는 기준월 금액+월 증가액. 적용 시작·종료 월, 예상/확정 상태.

**버튼·이동:** 월 행 선택·수정 → B07 / 예상 증가 설정 → B07 계산 모드 / 적용 변경 미리보기 → P07 재사용.

**추가 상태:** 음수 증감, 직접 확정월, 자동 예상월, 기준월 미입력. 목적통장 상세도 이 화면을 재사용하되 월 증가 설정은 사용자가 선택할 때 제공한다.

```text
P14 ‘자산 항목 상세’를 수아 비상금 예시로 디자인해줘. 상단에는 이름, 소유자 수아, 2026년 5월 금액 14,430,701원과 확정 배지가 있어.
아래에는 작은 추이 차트와 월별 금액 목록이 있어. 4월 13,730,701원, 5월 14,430,701원, 6월 예상 15,130,701원을 보여줘. 각 월을 눌러 편집할 수 있어.
‘예상 금액 설정’ 영역에는 ‘기준 금액에 매월 700,000원 더하기’와 적용 기간을 보여줘. 자동 예상값과 직접 확정한 값을 구분해줘. 같은 레이아웃으로 목적통장 상세도 사용할 수 있게 해줘.
```

### P15. 목적통장 현황

**목적:** 데이트·여행·경조사·효도용 통장의 월별 잔액을 기록한다.

**위에서 아래로:** 제목·월 → 입력 잔액 합계 → 통장 카드 목록 → 통장 추가.

**카드:** 이름, 해당 월 잔액, 입력 상태. 잔액을 모으면 표시할 수 있으나 저축 기록의 월 납입액을 잔액으로 표현하지 않는다.

**버튼·이동:** 통장 → P14 목적통장 모드 / 월 금액 편집·신규 통장 → B07.

**추가 상태:** 일부 통장 미입력, 모든 통장 미입력, 0원 잔액.

```text
P15 ‘목적통장 현황’을 디자인해줘. 2026년 5월 선택기와 ‘입력된 잔액 합계 2,000,000원’을 상단에 보여줘.
데이트통장 300,000원, 여행통장 700,000원, 경조사통장 600,000원, 효도통장 400,000원을 카드나 목록으로 표시해줘. 각 항목을 누르면 월별 잔액 상세로 이동하고 금액을 편집할 수 있어.
‘통장 추가’ 동작을 넣고, 일부 잔액이 미입력인 변형 화면도 만들어줘. 목표 금액이나 달성률은 추가하지 말고 현재 월 잔액 중심으로 그려줘.
```

### P16. 관리비 현황

**목적:** 청구월별 관리비 내역과 변화를 비교한다.

**위에서 아래로:** 제목·청구월 → 관리비 총합 → `상세 / 월별 비교` → 항목별 금액 또는 월별 표.

**상세 항목:** 원본의 21개 항목을 표시한다. 긴 목록은 관리·공용·사용료·조정으로 시각적 그룹을 나눌 수 있지만 합산 항목을 빠뜨리지 않는다.

**버튼·이동:** 입력·수정 → P17 / 월 → B01. 월별 비교는 연도를 넘긴 범위를 선택할 수 있다.

**추가 상태:** 미입력 월, 차감액, 연도 변경. 가계부 관리비로 반영 버튼은 별도 기능 확정 시 추가한다.

```text
P16 ‘관리비 현황’을 디자인해줘. 청구월 선택기 아래 관리비 총액을 크게 보여주고 ‘상세 / 월별 비교’ 탭을 배치해줘.
상세는 일반관리비, 청소비, 장기수선충당금, 세대전기료, 세대수도료, 세대난방비 등 항목별 금액 목록이야. 관리비차감은 -4,020원처럼 음수로 표시해줘. 총액은 실제로 표시한 상세 금액 합계와 일치하게 해줘.
월별 비교 탭에는 2025년 10월부터 2026년 2월까지 월별 합계와 비교 가능한 표를 보여줘. 하단에 ‘이번 달 관리비 입력’ 또는 기존 데이터가 있으면 ‘관리비 수정’을 배치해줘. 상세 목록은 세로 스크롤이 가능해야 해.
```

### P17. 관리비 입력·수정

**목적:** 고지서의 항목별 금액을 작성한다.

**위에서 아래로:** 청구월 → 입력 중 합계 → 세부 금액 필드 → 저장.

**전체 항목:** 일반관리비, 청소비, 소독비, 승강기유지비, 수선유지비, 장기수선충당금, 건물보험료, 경비용역비, 위탁관리수수료, 입주자대표회의, 선거관리위원회, 세대전기료, 공동전기료, 승강기전기, TV수신료, 세대수도료, 세대난방비, 기본난방비, 세대급탕비, 관리비차감, 생활폐기물수수료.

**버튼·이동:** 저장 → P16. 입력 합계는 자동이며 직접 수정하지 않는다.

**추가 상태:** 숫자 키보드, 다음 항목 이동, 부분 입력, 음수 차감. 전체 폼은 별도 프레임 또는 스크롤 아래 영역까지 그린다.

```text
P17 ‘관리비 입력’을 디자인해줘. 청구월 선택과 자동 합계를 상단에 두고 항목명 왼쪽, 원 단위 금액 입력 오른쪽인 긴 폼을 만들어줘. 하단 저장 버튼은 고정해줘.
항목은 일반관리비, 청소비, 소독비, 승강기유지비, 수선유지비, 장기수선충당금, 건물보험료, 경비용역비, 위탁관리수수료, 입주자대표회의, 선거관리위원회, 세대전기료, 공동전기료, 승강기전기, TV수신료, 세대수도료, 세대난방비, 기본난방비, 세대급탕비, 관리비차감, 생활폐기물수수료야.
항목은 시각적으로 그룹화하고 접을 수 있게 해줘. 관리비차감은 음수 입력이 가능하고 빈 필드는 미입력이야. 키보드의 다음 버튼으로 이어서 입력할 수 있는 화면과 하단 차감 영역까지 보여줘.
```

### P18. 더보기

**목적:** 부가 기록과 설정에 접근한다.

**위에서 아래로:** 가계부 이름·두 사람 이름 → 관리비 → 항목 관리 → 가계부 기본 설정 → 사용 가이드.

**버튼·이동:** 관리비 → P16 / 항목 → P19 / 기본 설정 → B09 / 가이드 → P20.

**추가 상태:** 아직 이름을 입력하지 않은 기본 설정 안내. 계정 연동 상태를 임의로 표시하지 않는다.

```text
P18 ‘더보기’를 디자인해줘. 하단 탭은 더보기가 선택되어 있어. 상단에 ‘모아로그’와 ‘수아 · 종민’을 보여줘.
메뉴는 관리비 현황, 항목 관리, 가계부 기본 설정, 사용 가이드 네 개야. 각 메뉴에 간단한 아이콘과 한 줄 설명, 이동 화살표를 붙여줘. 메뉴 그룹 간 여백을 충분히 두고 관리비 현황을 가장 먼저 배치해줘.
```

### P19. 항목 관리

**목적:** 각 목록에 사용하는 항목과 카테고리를 정리한다.

**위에서 아래로:** 관리 대상 선택 → 사용 중/보관됨 전환 → 목록 → 추가.

**관리 대상:** 수입 항목, 고정지출 항목, 변동지출 카테고리, 저축 항목, 관리비 항목. 저축의 6개 자산 분류는 현행 기본값으로 제시한다.

**버튼·이동:** 행 → B08 / 순서 편집 → 같은 화면 편집 모드 / 보관 → 확인 D02 / 복원 → 원래 목록.

**추가 상태:** 보관 목록, 빈 목록, 동일 이름. 사용 중인 항목의 이름을 바꿔도 기존 내역은 유지한다.

```text
P19 ‘항목 관리’를 디자인해줘. 상단 관리 대상 선택기는 수입 항목, 고정지출 항목, 변동지출 카테고리, 저축 항목, 관리비 항목을 선택할 수 있어.
변동지출 카테고리 상태를 먼저 그려줘. 생활비 초과, 데이트비, 여행비, 경조사비, 효도비, 기타 예산 목록이 있어. 사용 중/보관됨 전환, 항목 추가, 순서 편집을 제공해줘.
일반 목록, 순서를 바꾸는 편집 모드, 보관된 항목의 복원 화면을 그려줘. 보관은 과거 기록을 삭제하는 동작처럼 보이지 않게 해줘.
```

### P20. 사용 가이드

**목적:** 시트에서 하던 업무를 앱에서 어떻게 수행하는지 설명한다.

**위에서 아래로:** 시작 순서 → 자주 쓰는 기능 → 계산 기준 질문과 답변 → 관련 화면 바로가기.

**내용:** 월급 배분 → 고정비 점검 → 월별 계획 → 지출 기록 → 저축·자산 점검. 귀속 월과 일자, 예상/확정, 과소비, 목적통장 포함/순저축, 자산 잔액과 납입액의 차이.

**버튼·이동:** 설명 내 해당 화면 열기. 뒤로 가면 직전 화면으로 돌아간다.

```text
P20 ‘사용 가이드’를 디자인해줘. 첫 구역은 ‘이 순서로 시작해보세요’이고 월급 배분, 고정비 점검, 월별 계획, 지출 기록, 저축·자산 확인의 다섯 단계야. 각 단계는 관련 화면 열기 동작이 있어.
아래에는 펼쳐서 읽는 도움말을 배치해줘. 질문은 ‘귀속 월과 실제 지출일은 어떻게 다른가요?’, ‘예상과 확정은 무엇인가요?’, ‘과소비는 어떻게 표시하나요?’, ‘목적통장 포함 저축과 순저축의 차이는?’, ‘저축액과 자산 잔액은 어떻게 다른가요?’야.
귀속 월 도움말 하나가 펼쳐진 상태를 그려줘. 설명은 ‘귀속 월은 합계에 반영할 달이고, 실제 지출일은 돈을 쓴 날짜예요. 서로 다르게 기록할 수 있어요.’로 사용해줘.
```

## 5. 공통 바텀시트 9종

다음 요소도 디자인에 포함한다. 해당 부모 화면을 어둡게 처리한 상태에서 패널을 보여주고, 각 바텀시트가 어느 화면에서 열리는지 프레임 이름에 적는다. 입력 항목이 많아지면 패널 내부 스크롤이나 전체 화면 높이 확장을 사용한다.

| ID | 이름 | 부모 화면 | 구성과 동작 |
|---|---|---|---|

### 바텀시트 디자인 요청문

```text
앞서 만든 앱 스타일로 B01~B09 공통 바텀시트를 각각 그려줘. 각 패널은 드래그 핸들, 명확한 제목, 닫기, 하단 주요 버튼을 갖고 키보드와 겹치지 않아야 해.
B01 기간 선택: 연도와 12개월 그리드, 선택 강조, 적용 버튼. 연간 선택은 구성 분석처럼 허용하는 부모 화면에만 있어.
B02 저축 목표: 2026년, 50,000,000원 입력, 저장.
B03 지출 필터: 카테고리 다중 선택, 과소비 전체/체크만, 최신순/오래된순, 초기화, 적용.
B04 월급 수정: 수아 3,200,000원, 종민 3,300,000원 입력, 합계 6,500,000원, 저장.
B05 고정비 점검 항목: 공동/수아/종민 선택, 항목명, 월 금액, 저장.
B06 배분 항목 편집: 항목명, 상위 항목, 계산 방식 선택. 방식은 직접 금액, 월급 비율, 선택한 하위 항목 합계, 상위 금액에서 선택 항목 차감이야. 선택한 방식에 필요한 금액·비율·항목 선택만 보여줘. 거래수단도 입력할 수 있어.
B07 자산·통장 편집: 신규 항목 모드와 월 금액 수정 모드, 예상 증가 설정 모드를 그려줘. 예상 설정에는 기준월, 기준 금액, 월 증가액, 적용 기간, 변경 미리보기 버튼이 있어.
B08 항목 편집: 이름·분류 입력, 저축일 때 목적통장 여부·순저축 포함 여부, 저장.
B09 기본 설정: 가계부 이름, 두 사람 이름, 저장.
하단 패널에 입력이 많으면 내부 스크롤이 되거나 전체 높이로 확장되도록 해줘. 각 패널은 부모 화면 위에 열린 모습으로 그려줘.
```

## 6. 확인창과 공통 상태

확인창은 별도 페이지로 만들지 않고 공통 컴포넌트로 재사용한다.

| ID | 상황 | 문구 예시 | 버튼 |
|---|---|---|---|
| D01 | 지출 삭제 | 이 지출을 삭제할까요? 월별 합계에도 반영돼요. | 취소 / 삭제 |
| D02 | 항목 보관 | 이 항목을 보관할까요? 기존 기록과 합계는 유지돼요. | 취소 / 보관 |
| D03 | 편집 중 뒤로 가기 | 저장하지 않은 변경 사항이 있어요. | 계속 작성 / 나가기 |
| D04 | 특정 월 금액 지우기 | 2026년 5월 금액만 지울까요? 항목은 유지돼요. | 취소 / 지우기 |

**대표 상태 프레임:** P02 빈 홈, P11 기록 없음·필터 결과 없음, P12 입력 오류·저장 실패, P14 예상값, P17 부분 입력을 그린다. 저장 중에는 버튼 로딩과 중복 탭 방지를, 실패 시에는 입력값과 재시도 버튼을 유지한다. 계정·서버 방식이 미정이므로 온라인 동기화 상태를 임의로 확정하지 않는다.

성공 후에는 ‘저장했어요’ 같은 짧은 메시지와 갱신된 목록으로 돌아간다. 일반 저장마다 별도 완료 화면을 만들지 않는다.

## 9. 구버전 기능을 포함할 때 추가할 화면

구버전 포함 여부가 정해지면 아래 두 화면을 추가한다. 현행 20종의 필수 디자인에는 포함하지 않는다.

**X01 개인 용돈:** 수아/종민 선택 → 시작일·종료일 → 목표 용돈·사용액·남은 금액 → 개인 지출 목록. 목표 및 기간은 바텀시트, 지출 입력은 P12를 개인 용돈 모드로 재사용한다. 개인 용돈 상세는 가계부에 이미 잡힌 용돈과 이중 합산하지 않는다.

**X02 개인별 연간 요약:** 연도 → 사람별 수입·저축·저축률 → 월별 비교. 전체 가계부 합계와 개인 합계를 구분한다.

```text
선택 화면 X01 ‘개인 용돈’을 디자인해줘. 수아/종민 선택, 기간 5월 1일~5월 31일, 목표 300,000원, 사용 120,000원, 남은 용돈 180,000원과 개인 지출 목록을 보여줘. 기간·목표 수정과 지출 추가 버튼이 있어.
선택 화면 X02 ‘개인별 연간 요약’을 디자인해줘. 연도 선택, 사람별 연 수입·저축·저축률, 월별 비교를 보여줘. 일반 가계부와 같은 스타일을 사용해줘.
```

## 10. 디자인 검토 기준

- 다섯 하단 탭에서 모든 기본 화면으로 이동할 수 있는가?
- 지출을 새로 입력하고 수정·삭제하는 흐름이 끊기지 않는가?
- 귀속 월과 실제 일자가 따로 보이는가?
- 수입·지출·저축·보유 자산이 서로 다른 수치로 읽히는가?
- 금액이 큰 경우와 항목명이 긴 경우에도 읽을 수 있는가?
- 예상·확정·미입력·0원·음수 상태가 구분되는가?
- 저축 달성률이 100%를 넘어도 실제 숫자를 표시하는가?
- 월급 배분액과 하위 합계의 차이가 숨겨지지 않는가?
- 연간 표를 작은 모바일 화면에서도 탐색할 수 있는가?
- 긴 관리비 입력에서 현재 합계와 저장 버튼에 접근할 수 있는가?
- 입력된 값과 자동 계산된 값의 편집 가능 여부가 명확한가?
- 원본 수식 오류나 데이터 매핑 같은 구현 설명이 사용자 화면에 노출되지 않는가?

화면 설계는 기존 기능 명세의 계산 수정안을 시각화한 초안이다. 기초 잔액·순저축 포함 정책과 구버전 기능 범위는 기존 명세의 결정 사항을 유지한다.
