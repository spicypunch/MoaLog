## 1. 기획 목적과 범위

현재 Google Sheets에서 수행하는 두 사람의 월급 배분, 고정비 점검, 월별 수입·지출·저축 기록, 연간 결산, 목적통장 및 자산 추적, 관리비 기록을 앱에서 수행할 수 있게 한다. 시트의 업무와 계산을 유지하면서 셀 입력을 앱의 입력 폼과 목록으로 옮긴다.

이 문서에서 **원본 확인**은 셀 값·수식·사용 가이드에서 확인한 기능이고, **앱 전환안**은 그 기능을 앱에서 표현하는 설계다. **결정 필요**는 원본만으로 의도를 확정할 수 없는 사항이다. 원본의 잘못된 참조를 수정하는 안은 별도로 제시하며, 기존 결과가 동일하다고 간주하지 않는다.

대상 플랫폼, 기술 스택, 두 사람의 별도 로그인·동기화 방식은 미정이다. 은행·카드 자동 연동, 자동 송금, 투자 추천 등 원본에 없는 기능은 이번 기능 이관 범위에 포함하지 않는다.

## 3. 앱 정보 구조와 주요 사용 흐름

모바일 기준 탐색 구조를 다음과 같이 제안한다. 플랫폼이 정해져도 기능 대응은 유지한다.

| 메뉴 | 하위 화면 | 주된 작업 |
|---|---|---|
| 홈 | 연간 요약, 목표, 구성 비중 | 전체 흐름 확인 |
| 계획 | 월급 배분, 고정비 점검, 월별/연간 계획 | 수입·지출·저축 금액 작성 |
| 기록 | 변동지출 목록, 입력, 과소비 필터 | 지출 추가·수정·조회 |
| 자산 | 저축·투자, 월별 자산, 목적통장 | 저축 및 보유 금액 관리 |
| 더보기 | 관리비, 항목 설정, 사용 안내 | 상세 관리와 설정 |

‘계획’과 ‘자산’에서 여는 저축·투자 기록은 같은 데이터다. 서로 다른 화면에 같은 금액을 중복 저장하지 않는다.

**최초 작성:** 기준 연도와 두 사람 표시명 설정 → 월급 배분 작성 → 공동·개인 고정비 점검 → 연간 수입·고정지출·저축 입력 → 연 저축 목표 입력.

**평소 기록:** 기록 메뉴 → 귀속 월·카테고리·금액 입력 → 필요하면 일자·상세·과소비 체크 → 저장 → 월별 집계와 홈 자동 갱신.

**월별 점검:** 해당 월 선택 → 예상 금액 확정 또는 수정 → 관리비 입력 → 저축 및 자산 현황 갱신 → 월별 결과와 연간 목표 확인.

## 4. 화면별 기능 명세

### S01. 홈 / 연간 결산

- 기준 연도, 연 저축 목표, 총수입, 총지출, 총저축, 저축률, 저축 달성률을 표시한다.
- 목표액 수정 시 달성률을 즉시 다시 계산한다. 목표액은 연도별로 저장하는 앱 전환안을 적용한다.
- 원본의 상단 총저축은 ‘목적통장 포함 저축’ 합계다. 이를 임의로 수입에서 지출을 뺀 값으로 대체하지 않는다.
- 각 요약 항목을 누르면 해당 연간 상세로 이동한다.
- 고정지출 구성과 저축·투자 구성은 원본처럼 연간 기준으로 제공한다.
- 변동지출 구성은 1~12월 또는 연간 합계를 선택한다. 선택 기간을 차트 제목에 명시한다.
- 과소비는 사용자가 체크한 지출의 합계로 표시한다. 지출액이 일정 수준을 넘었다고 자동 과소비로 분류하지 않는다.
- 예상 금액도 원본 연간 합계에 포함된다. 앱에서도 ‘예상 포함 연간 합계’임을 표시한다. 실제 지출 완료액처럼 보이지 않게 한다.

### S02. 월급 배분

원본 확인: 두 사람 월급을 합산하고, 생활비·용돈·목적통장·고정변동비·투자로 나누어 배분한다. 하위 항목과 거래수단을 함께 기록한다.

| 입력/출력 | 동작 |
|---|---|
| 두 사람 월급 | 각각 금액 입력, 총월급 자동 합계 |
| 대분류 | 이름, 금액 계산 방식, 기준 비율 또는 금액 |
| 중분류·소분류 | 항목명, 금액, 필요 시 개인 구분 |
| 거래수단 | 통장·카드·명의 등 원본 자유 텍스트 보존 |
| 비율 기준 배분 | 총월급 × 입력 비율로 계산 |
| 하위 합계 | 선택한 하위 항목 합산 |
| 잔여액 계산 | 상위 금액에서 지정 하위 항목을 뺀 값 |

원본에는 총월급의 10% 용돈, 15% 목적통장, 25% 고정변동비, 40% 투자 계산이 있다. 이 비율을 고정 서비스 정책으로 만들지 않고 수정 가능한 값으로 취급한다.

원본의 계획 금액과 하위 입력 합계는 서로 다를 수 있다. 예를 들어 투자 배분액은 2,600,000원이지만 하위 합계는 2,500,000원이다. 두 값을 모두 보여주고 차액 100,000원을 표시하는 앱 전환안을 사용한다. 하위 금액을 자동 변경해 차액을 없애지 않는다.

항목명에 적힌 ‘데이트(11%)’ 등의 비율은 실제 수식이 아닌 텍스트일 수 있다. 원본 이름만 보고 자동 계산 규칙을 만들지 않는다. 금액·비율·이름을 별도 필드로 매핑한다.

월급 배분표는 원본에서 독립적으로 관리된다. 수정했다고 연간 계획을 자동 덮어쓰지 않는다. 연간 계획으로 가져오기 기능을 제공한다면 대상 월과 변경 금액을 보여주는 명시적 복사 동작으로 설계한다.

### S03. 고정비 점검

- 공동, 사람 A, 사람 B로 구분해 항목명과 월 금액을 입력한다.
- 그룹별 합계와 전체 합계를 자동 표시한다.
- 원본의 아내·남편 표시는 사용자가 정한 이름 또는 호칭으로 표현할 수 있게 한다.
- 점검용 목록과 실제 연간 고정지출 목록은 분리한다. 점검 후 확정 항목을 실제 가계부로 옮기는 원본 흐름을 유지한다.
- 앱 전환안: 선택 항목을 선택한 월에 복사한다. 같은 항목이 이미 존재하면 덮어쓰기/유지 대상을 표시한다.
- 원본의 ‘연간 합계’ 열은 월 금액을 그대로 합산한다. 월 금액 × 12로 수정할지는 8절의 결정 사항이다.

### S04. 월별 / 연간 계획

공통 UI는 수입·고정지출·저축/투자 세 구역과 읽기 전용 변동지출 집계 구역으로 구성한다. 모바일에서는 선택 월의 목록이 기본이고, 12개월 전체를 비교할 수 있는 연간 표를 제공한다.

| 구역 | 입력 항목 | 자동 산출 |
|---|---|---|
| 수입 | 항목명, 월 금액, 필요 시 개인 구분 | 월수입·연수입 |
| 고정지출 | 분류, 항목명, 월 금액 | 공동 합계·고정지출 합계·연 합계 |
| 변동지출 | 상세 기록 화면에서 입력 | 월/분류별 지출, 월 총지출 |
| 저축·투자 | 자산 분류, 항목명, 월 금액 | 목적통장 포함/제외 합계·저축률 |

- 월별 금액을 독립 수정한다. 급여 인상, 보험료 변경 등 특정 월 변화가 다른 월을 바꾸지 않는다.
- 원본의 매월 복사·붙여넣기는 ‘다음 달 복사’와 ‘선택한 여러 월에 적용’으로 대체한다.
- 기존 값이 있는 월에 일괄 적용할 때 변경 내역을 미리 표시한다.
- 원본의 파란 글씨 예상값·검은 글씨 확정값은 ‘예상/확정’ 상태로 전환한다. 상태와 금액은 각각 수정 가능하다.
- 금액 확정은 새 거래를 추가하는 것이 아니라 기존 월 항목의 상태 변경이다.
- 주거비·교통비·생활비·보험·통신비·비상금·구독·개별 용돈을 기본 고정지출 분류로 제공한다.
- 변동지출 합계는 상세 기록에서 계산하며 직접 덮어쓸 수 없다.
- 수입·지출·저축은 원본처럼 각각 입력한다. 수입과 지출 차액을 자동으로 저축 입금액으로 기록하지 않는다.

### S05. 변동지출 기록

| 필드 | 필수 | 규칙 |
|---|---|---|
| 귀속 연월 | 필수 | 해당 지출을 집계할 연월 |
| 일자 | 선택 | 실제 거래일, 귀속 월과 별도 저장 |
| 카테고리 | 필수 | 등록된 변동지출 항목 선택 |
| 상세 내용 | 선택 | 자유 텍스트 |
| 금액 | 필수 | 원 단위 정수, 빈값과 0 구분 |
| 과소비 | 선택 | 기본 해제, 사용자 직접 선택 |
| 과소비 금액 | 자동 | 체크 시 해당 금액, 해제 시 0 |

기본 카테고리는 생활비 초과, 데이트비, 여행비, 경조사비, 효도비, 기타 예산이다.

목록은 귀속 월·카테고리·과소비 여부로 필터링하고 일자순으로 정렬한다. 내용과 금액 수정·삭제 시 연결된 모든 합계를 갱신한다. 일자가 없는 기록은 정렬 시 별도 표시한다.

원본에는 실제 일자가 2월인데 귀속 월은 1월인 기록이 있다. 앱은 일자로 귀속 월을 강제 변경하지 않는다. 새 입력에서는 일자 기준 월을 제안하되 사용자가 바꿀 수 있다.

‘생활비 초과’는 별도 변동지출 항목이다. 고정지출로 잡아둔 생활비 전체를 다시 더하지 않는다. 원본 방식대로 초과분을 입력할 수 있게 한다.

원본의 과소비는 금액 전체를 포함하는 체크다. 부분 금액 지정이나 자동 예산 초과 판정은 기본 이관 기능에 추가하지 않는다.

### S06. 저축·투자

- 기본 분류는 예적금, 청약, 주식, 부동산, 대출원금, 퇴직금이다. 사용 가이드에서 고정된 선택지로 설명한다.
- 적금, 개인별 ISA, 퇴직연금, IRP, 비상금, 데이트·여행·경조사·효도 통장 등의 항목을 등록한다.
- 월 금액은 양수·0·음수를 지원한다. 원본의 비상금 인출을 음수로 기록하는 기능을 유지한다.
- ‘목적통장 포함 저축’과 ‘순 저축 합계’를 동시에 제공한다.
- 앱 전환안: 항목별로 목적통장 여부와 순저축 포함 여부를 저장한다. 원본에서 행 위치로 정한 합계 범위를 명시적 항목 속성으로 바꾼다.
- 원본에서 순저축의 비상금 포함 범위가 일부 월마다 다르다. 단일 규칙으로 통일하기 전 사용자 확인이 필요하다.
- 저축액·보유 잔액·투자 평가수익을 구분한다. 원본에 섞인 과거 잔액을 신규 저축으로 자동 해석하지 않는다.

### S07. 월별 자산 및 목적통장 현황

원본에는 연간 저축표와 별개로 월별 자산 표가 있다. ISA 원금과 수익, 주식, 두 사람 비상금, 적금의 합계와 전월 대비 증감을 관리한다.

- 자산 항목별 월 금액을 기록하고 해당 월 총합 및 전월 대비 증감을 표시한다.
- 첫 기준월을 입력하고 이후 월을 ‘전월 금액 + 월 증가액’으로 채우는 방식을 지원한다. 원본의 미래월 수식을 앱 계산으로 대체한다.
- 미래 예상 금액은 예상 표시를 한다. 실제 금액 확정 시 해당 월을 수정한다.
- 중간 월이 수정되면 그 이후 자동 계산 월만 재계산한다. 직접 입력한 확정 월은 덮어쓰지 않는 앱 전환안을 제안한다.
- ISA 원금과 수익이 별도 열로 존재하므로 합산 시 원금과 수익을 각각 한 번만 포함한다. 평가금액과 원금+수익을 동시에 더하지 않는다.
- 목적통장 현황은 별도 월 금액을 수동 입력할 수 있게 한다. 원본 ‘여핼’ 표기는 원문을 보존하되 ‘여행’으로 정리할지는 확인한다.
- 목적통장 잔액과 저축표 납입액, 지출 상세는 원본에서 자동 연동이 확인되지 않았다. 기본 설계에서는 독립 기록으로 유지한다.

### S08. 관리비 현황

월별 관리비를 항목별로 입력하고 합계와 월별 비교표를 제공한다. 기록 범위는 연도를 넘길 수 있다. 원본은 2025년 10월부터 2026년 12월까지의 열을 사용한다.

기본 항목: 일반관리비, 청소비, 소독비, 승강기유지비, 수선유지비, 장기수선충당금, 건물보험료, 경비용역비, 위탁관리수수료, 입주자대표회의, 선거관리위원회, 세대전기료, 공동전기료, 승강기전기, TV수신료, 세대수도료, 세대난방비, 기본난방비, 세대급탕비, 관리비차감, 생활폐기물수수료.

- 항목별 원 단위 금액을 입력한다. 관리비차감과 같은 음수 항목을 허용한다.
- 빈 항목은 미입력 상태를 유지하되 합산에서는 0으로 취급한다.
- 합계는 모든 상세 항목의 부호를 유지해 계산한다.
- 관리비 총합과 가계부의 고정지출 ‘관리비’는 원본에서 값이 서로 다르다. 자동 동기화하지 않는다.
- 관리비를 고정지출에 반영하는 기능을 추가한다면 귀속 월과 기존 금액을 확인하는 명시적 동작으로 설계한다.

### S09. 항목 관리와 도움말

- 항목 이름·정렬·사용 여부를 관리한다. 사용하지 않는 항목 숨기기는 원본 행 숨기기에 대응한다.
- 항목명이 바뀌어도 기존 지출 집계가 끊기지 않도록 내부 식별자로 연결한다.
- 원본의 동일한 ‘수정 가능’ 등 중복 이름을 가져올 때는 행 식별자를 함께 보존하고 이름만으로 병합하지 않는다.
- 사용 중인 항목 삭제는 기존 기록을 보존하는 보관 처리로 전환한다.
- 임의 행 추가가 수식을 깨뜨리는 시트 제약은 앱에 재현하지 않는다. 기록 추가 시 집계 대상에 자동 포함한다.
- 입력값과 자동 계산값을 시각적으로 구분하고, 예상/확정 상태는 색상과 텍스트를 함께 사용한다.
- 메모는 항목 또는 월 입력값에 연결하는 전환안을 적용한다. 댓글·대화 기능은 두 사람의 사용 방식이 정해진 뒤 판단한다.

## 5. 계산 규칙

다음은 원본이 의도한 집계 기능의 앱 전환안이다. 실제 원본 결과와 다른 계산은 8절에서 추적한다. 금액은 원 단위 정수로 저장하고, 비율은 계산 후 화면에서 반올림한다.

| ID | 지표 | 계산 및 집계 기준 |
|---|---|---|
| C01 | 총월급 | 사람 A 월급 + 사람 B 월급 |
| C02 | 비율 배분액 | 총월급 × 비율. 원 미만 반올림은 앱 정책 제안 |
| C03 | 항목 연 합계 | 선택 연도 1~12월 금액 합계 |
| C04 | 월 총수입 | 해당 월 수입 항목 합계 |
| C05 | 월 고정지출 | 해당 월 고정지출 항목 합계. 그룹 소계는 중복 합산하지 않음 |
| C06 | 월/카테고리 변동지출 | 귀속 연월과 카테고리가 일치하는 상세 금액 합계 |
| C07 | 월 변동지출 | 해당 월의 모든 활성 집계 대상 카테고리 지출 합계 |
| C08 | 월 총지출 | 월 고정지출 + 월 변동지출 |
| C09 | 월 과소비 | 해당 귀속 월의 과소비 체크 금액 합계. 총지출에 다시 더하지 않음 |
| C10 | 목적통장 포함 저축 | 해당 월 저축·투자 항목 전체 금액 합계 |
| C11 | 순저축 | 해당 월 순저축 포함 대상으로 지정된 항목 합계 |
| C12 | 저축률 | 목적통장 포함 저축 ÷ 같은 기간 수입 × 100 |
| C13 | 순저축률 | 순저축 ÷ 같은 기간 수입 × 100 |
| C14 | 목표 달성률 | 연간 목적통장 포함 저축 ÷ 연 목표 × 100 |
| C15 | 구성 비중 | 같은 기간의 해당 분류 금액 ÷ 같은 기간 전체 금액 × 100 |
| C16 | 월 자산 총액 | 해당 월 자산 표의 항목 금액 합계 |
| C17 | 자산 증감 | 해당 월 자산 총액 − 전월 자산 총액 |
| C18 | 관리비 총합 | 해당 청구월 상세 항목 합계. 차감액 부호 유지 |

공통 예외 처리:

- 수입 또는 목표가 0/미입력이면 해당 비율을 ‘계산 불가’ 또는 ‘—’로 표시한다. 0%로 오인시키지 않는다.
- 비율이 100%를 넘거나 음수여도 원래 수치를 보존한다. 목표 진행 막대만 100%에서 멈추더라도 숫자는 실제 비율을 표시한다.
- 빈값은 0과 별도 상태로 저장한다. 합계는 빈값을 0으로 처리하되 월 전체 미입력은 ‘미입력’으로 표시한다.
- 수정·삭제 시 상세와 요약을 함께 갱신한다. 숨김은 집계 제외가 아니다.
- 음수로 원형 차트 표현이 어려우면 금액 표와 막대 형태로 대체하고 음수를 버리지 않는다.
- 연간 저축률은 월 저축률 평균이 아니라 연간 금액 합계의 비율이다.
- 연간 합계는 달력상의 12개월을 사용한다. 원본의 11월·12월 사이 빈 열은 데이터로 옮기지 않는다.

## 6. 데이터 항목 정의

기술 스택과 관계없이 필요한 논리 데이터다. 별도 서버 도입을 전제로 하지 않는다.

| 데이터 | 주요 필드 | 역할 |
|---|---|---|
| 가계부 | id, 표시명, 기준 통화 | 하나의 가계부 구분 |
| 구성원 | id, 가계부 id, 이름/호칭 | 사람별 급여·비용 구분. 로그인 계정과 별개 |
| 연도 설정 | 가계부 id, 연도, 목표 저축액 | 연도별 목표 관리 |
| 항목 | id, 종류, 분류 id, 이름, 구성원/공동, 목적통장 여부, 순저축 포함 여부, 순서, 보관 여부 | 입력·집계 기준 |
| 월별 입력 | 항목 id, 귀속 연월, 금액/빈값, 예상·확정·미확인 상태, 메모 | 수입·고정지출·저축 |
| 배분 항목 | 상위 id, 이름, 계산 방식, 비율/고정액, 참조 항목, 거래수단 | 월급 배분표 |
| 고정비 점검 | 구성원/공동, 항목명, 월 금액 | 확정 전 점검표 |
| 지출 기록 | id, 귀속 연월, 거래일, 카테고리 id, 상세, 금액, 과소비 여부 | 변동지출 원장 |
| 자산 월 기록 | 항목 id, 연월, 금액, 직접입력/전월증가 방식, 증가액, 예상/확정 상태 | 자산 추이 및 목적통장 |
| 관리비 상세 | 청구 연월, 항목 id, 금액/빈값 | 관리비 총합의 원천 |
| 원본 연결 정보 | 탭 id, 셀/행, 원본 값, 수식, 이관 판단 | 이관 대조와 오류 추적 |

월별 입력은 ‘가계부 + 항목 + 연월’당 하나를 기본으로 한다. 반면 지출 기록은 같은 날짜·금액·내용의 복수 기록을 허용한다. 중복처럼 보여도 자동 삭제하지 않는다.

금액 합계와 차트 데이터는 원천 데이터에서 계산한다. 수동 요약값과 원천 데이터가 별도로 수정되어 불일치하는 구조를 만들지 않는다.

## 7. 데이터 이전과 앱 전환 정책

기능 구현과 실제 데이터 가져오기는 구분한다. 실제 이전을 수행할 경우 다음 절차를 적용한다.

1. 현행 5개 탭의 사용자 입력과 계산값을 구분해 추출한다. 구버전은 별도 보관 후보로 둔다.
2. 연도 없는 월 열의 기준 연도를 확인한다. 거래일이 2026년이라고 모든 계획값의 연도를 자동 확정하지 않는다.
3. 이름, 항목, 귀속 월, 금액, 음수, 거래수단, 메모를 매핑한다. 병합 셀의 빈칸은 확인된 그룹 범위 안에서만 해석한다.
4. 합계 행·차트 보조표·과소비 보조값은 거래로 가져오지 않는다. 계산 결과 비교용으로 보존한다.
5. 수식이 들어 있는 사용자 금액은 계산된 금액과 원래 표현식을 함께 보존한다. 일반 금액의 임의 수식 편집기는 기본 범위가 아니며, 반복·합산·차감·비율 기능으로 대체한다.
6. 원본 상태를 명확히 판별할 수 없는 예상/확정값은 ‘미확인’으로 둔다. 색상·노트의 상세 매핑은 실제 이관 시 추가 조회한다.
7. 월별 수입·고정지출·변동지출·저축·과소비·관리비·자산을 원본과 대조한다.
8. 오류 수정으로 생긴 차액은 수정 근거와 함께 별도로 제시한다. 원본 값과 앱 재계산값을 조용히 바꾸지 않는다.

스프레드시트와 앱의 계속 동기화는 원본에 없는 별도 기능이다. 이번 기획은 시트의 업무를 앱으로 이관하는 범위이며 실시간 양방향 동기화는 미정이다.

## 9. 구버전 고유 기능 보존 목록

구버전까지 옮기기로 결정하면 다음 기능을 추가한다.

- 사람별 수입·저축 합계와 개인 저축률.
- 공동 변동지출과 두 사람의 개인 용돈 지출 원장을 구분.
- 개인별 용돈 목표, 시작일·종료일, 기간 내 사용액, 남은 용돈.
- 개인 용돈의 카테고리별 월/연 집계.
- 날짜 기간 집계와 귀속 월 집계를 구분.

현행에서는 개인 용돈을 고정지출에 이미 포함한다. 개인별 용돈 상세까지 도입할 경우 상세 사용액을 총지출에 다시 더하지 않는 관계를 설계해야 한다. 구버전의 총지출 계산을 현행 계산과 그대로 합치지 않는다.

## 12. 분석 근거와 한계

- 6개 탭의 메타데이터, 현행 입력 영역과 요약값, 사용 가이드, 주요 집계 수식을 확인했다.
- 현행 지출 표는 하단 과소비 합계 영역까지 조회했으며, 중간의 값 없는 행에 있는 자동 0은 사용자 거래로 취급하지 않았다.
- 구버전은 주요 연간 집계와 개인 용돈 기능을 확인했다. 구버전 전체 데이터 이전 검증은 수행하지 않았다.

- 본 문서는 앱 기능과 화면 설계를 위한 산출물이며 원본 시트는 수정하지 않았다.
