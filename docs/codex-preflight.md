# Codex Preflight

1. 사용자 요청과 최신 대화 범위를 확인한다.
2. `git status --short --untracked-files=all`로 기존 변경을 확인한다.
3. 작업 소유 모듈과 의존 방향을 `ARCHITECTURE.md`에서 확인한다.
4. UI는 화면 규칙, Gradle은 모듈 규칙, 설정은 환경 문서를 읽는다.
5. 비밀값과 다른 프로젝트의 제품 코드를 복사하지 않는다.
6. 소유 모듈의 가장 작은 테스트부터 실행하고 최종 호스트 컴파일로 넓힌다.
7. 실행하지 않은 기기 QA나 배포를 완료로 보고하지 않는다.
